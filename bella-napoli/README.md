Bella Napoli – Restaurant Landing Page

A modern and professional website designed for an Italian restaurant, featuring a responsive layout and smooth interactions.

Features:
-Modern, clean design with warm color tones
-Fully responsive layout for desktop, tablet, and mobile
-Smooth transitions and hover effects
-SEO-ready HTML structure
-Clean, lightweight, and optimized code
-Functional table reservation form
Sections:
-Navigation bar with fixed menu and logo
-Hero section with call to action
-Restaurant features
-Menu showcase with prices
-About section with restaurant story and values
-Image gallery
-Contact section with reservation form and contact details
-Footer with additional links and information

Customization
Colors

Edit the CSS variables in style.css:

:root {
  --primary-color: #d4145a;
  --secondary-color: #fbb03b;
}

Content
Update index.html to change text content, menu items, prices, and contact information.

Images
Replace placeholder backgrounds with real images by adding them to the project folder and updating the background styles in index.html or style.css.

Browser Compatibility
Chrome, Firefox, Safari, Edge, and mobile browsers.
